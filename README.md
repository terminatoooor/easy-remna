# Remnanode Manager

اسکریپت مدیریت آسان نودهای Remnanode با منوی تعاملی و ساده.
با این اسکریپت می‌تونی به راحتی نود نصب کنی، حذف کنی، آپدیت کنی و لیست نودهای نصب‌شده رو ببینی — بدون نیاز به حفظ کردن دستورات داکر.

## ✨ امکانات

- ✅ نصب خودکار Docker در صورت نیاز
- ✅ نصب نود جدید با گرفتن فقط نام (بدون نیاز به تایپ مسیر کامل)
- ✅ حذف کامل نود (پایین آوردن کانتینر + پاک کردن پوشه)
- ✅ آپدیت نود با یک دستور
- ✅ لیست تمام نودهای نصب‌شده روی سرور
- ✅ منوی تعاملی و راحت برای استفاده

## 📋 پیش‌نیاز

- سرور اوبونتو / دبیان
- دسترسی root یا sudo
- اتصال به اینترنت

## 🚀 نصب و اجرا

روی سرورت این دستورات رو اجرا کن:

```bash
curl -O https://raw.githubusercontent.com/terminatoooor/easy-remna/main/node-manager.sh
chmod +x node-manager.sh
sudo ./node-manager.sh
```

## 📖 راهنمای استفاده

بعد از اجرای اسکریپت، این منو نمایش داده می‌شه:

```
===== Node Manager =====
1) Install Node
2) Remove Node
3) Update Node
4) List Nodes
0) Exit
=========================
```

| گزینه | توضیح |
|-------|-------|
| **1) Install Node** | چک می‌کنه Docker نصبه یا نه (در صورت نیاز نصبش می‌کنه)، بعد اسم نود رو ازت می‌پرسه (مثلاً `example`)، فایل `docker-compose.yml` رو با nano باز می‌کنه تا تنظیماتش رو وارد کنی، و بعد از ذخیره، نود رو اجرا می‌کنه. |
| **2) Remove Node** | اسم نود رو می‌گیره، کانتینرش رو پایین می‌آره و پوشه‌ش رو کامل حذف می‌کنه. |
| **3) Update Node** | اسم نود رو می‌گیره و یک دور down/up انجام می‌ده تا آپدیت بشه. |
| **4) List Nodes** | لیست تمام نودهایی که توی `/opt/remnanode` نصب شدن رو نشون می‌ده. |

تمام نودها به صورت خودکار داخل مسیر `/opt/remnanode/<node-name>` ذخیره می‌شن.
